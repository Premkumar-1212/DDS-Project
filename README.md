🅿️ Smart Parking Lot Management
Concept:
Manage a parking lot with entry/exit tracking.

Features:

Add (park) cars with vehicle numbers

Remove (exit) cars

Show all parked cars

Overflow alert when lot is full

Tech Used:

👉 Linked List for active parked cars

👉 Dynamic memory for parking slots

👉 Handles overflow when the parking is full

📒 Contact Book
Concept:
Store, search, update, and delete contact information in a persistent way.

Features:

Add new contacts

Search by name

Update or delete contacts

Display all sorted contacts

Data is saved in a file for next session!

Tech Used:

👉 Self-referential (linked list) structures

👉 File I/O for persistence

👉 Inserts new contacts in alphabetical order

💬 Chat Message History Manager
Concept:
Store outgoing chat messages and provide easy undo/redo support.

Features:

Send new chat messages

View all sent messages

Undo a sent message

Redo a message if undone

Every message has a timestamp!

Tech Used:

👉 Queue for incoming messages

👉 Stack for undo/redo

👉 Timestamp tracking for every message
